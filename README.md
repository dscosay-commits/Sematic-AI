# Sematic-AI
This is Sematic AI your offline AI assistant designed to answer academical queries.
It uses a dataset infrastructure to answer questions in simpler terms 'Dataset refers to a collection of scanable knowledge and data', in SAI's case it uses matching where by it scans your quetion and links it with its answer all in a split second.
The black bar in the center is the Dynamic Island ( Apple Inc don't sue me ) but just joking it's called the Sematic Island ( SI ), it is a live system indicator to show what SAI is currently doing.
